# 手势导航 · Hand Gesture Navigator（Microsoft Edge 扩展）

> **项目定位**：这是一个基于浏览器手势识别的 Edge 手势导航**实验项目**，
> 用来尝试通过摄像头手势完成页面缩放、视频控制、关闭标签页等操作。
> **纯属图一乐，实用价值有限**——请把它当作一个好玩的原型，而不是成熟的生产力工具。
>
> **来源声明**：本项目是在开源项目 **[Wencle-Sun/globe（深空制图仪）](https://github.com/Wencle-Sun/globe)**
> 基础上进行**二次开发**的实验性项目。手势识别的核心机制移植并改写了 globe 的实现
> （原作者 Wenke Sun，MIT License），并非完全原创。
> 哪些代码来自上游、哪些是本项目新增，见下文[「来源与许可」](#八来源与许可)一节与
> `docs/原项目实现分析.md`、`THIRD_PARTY_LICENSES/THIRD_PARTY_NOTICES.md`。

用摄像头手势控制当前网页：**12 条指令自由绑定 6 个手势槽位**（缩放、播放/暂停、前进/回退、
音量、滚动、下一集、复制链接、切换/关闭标签页）。
按 Edge Extension（Manifest V3）的安全与 API 限制做了架构改造。
手部识别基于本地打包的 MediaPipe Hands WASM，**画面不出浏览器、零网络依赖**。

## 一、安装（Edge 开发人员模式加载）

1. 打开 Edge，地址栏进入 `edge://extensions/`
2. 打开左下角 **开发人员模式** 开关
3. 点击 **加载解压缩的扩展**，选择本目录（`gesture-nav-edge`）
4. 安装成功后点击工具栏的手势图标，在右侧 **侧边栏** 中点「▶ 启动手势」
5. 首次使用如浏览器询问摄像头权限，请点允许（清单已声明 `camera` 权限，通常不会再询问）

> 旧版本 Edge（无侧边栏 API）会自动退回：点击图标时把控制面板作为普通标签页打开，功能一致。

## 二、手势一览（v1.0.5 · 可自定义，下表为默认绑定）

| 手势 | 动作 | 防误触设计 |
| --- | --- | --- |
| 🤲 双手同时向外 / 向内移动 | 页面放大 / 缩小（连续） | IDLE→START→ACTIVE→END 会话状态机；EMA 平滑 + 滞回 + 单帧限速；30%~400% 限幅；丢手立即 CANCEL |
| ✌️ V 型手势保持约 0.6 秒 | 视频播放 / 暂停 | 连续 ≥3 帧姿态确认 + 保持计时；一次保持只触发一次；1s 冷却 |
| 👌 OK 手势保持约 0.8 秒 | **关闭当前标签页** | 倒计时环可见进度；保持 3s 也只一次；1s 冷却；设置中可禁用 |
| 👊 握拳保持 0.8 秒 | 视频回退 10 秒 | 四长指+拇指全收拢才判为握拳；与 OK（要求三指伸直）互斥 |
| ☝️ 只伸食指（其余含拇指全收拢）保持约 0.4 秒 | 跳转播放下一集 | 先试常见播放器控件，再按"下一集/next"文本匹配；找不到入口只提示不报错 |
| 🤟 收起拇指、伸出其余四指保持约 0.4 秒 | 复制当前网页链接到剪贴板 | 剪贴板 API 失败自动走 execCommand 兜底；1.2s 冷却 |

（v3.1 的"拜拜摇手暂停/恢复"手势已删除；"页面上下滚动"与"切换上/下标签页"在 V1.0.5 作为可绑定指令回归指令库，不再是默认绑定。）

**生命周期契约**：保持类手势必须走完
`候选(连续≥3帧姿态确认) → 保持计时 → 触发一次 → LOCKED(姿态释放才解锁) → 冷却(1s) → 重新待命`；
双手缩放走独立会话状态机。同一手势持续在画面中绝不重复触发；
保持进行中因运动模糊丢跟踪 ≤6 帧会保留计时续算，超时消失则全量复位。

**精度层**（保留）：完整关键点模型（modelComplexity=1）+ 1280×720 采集 +
"重捕获友好"置信度（0.5）+ 30fps 节流 + 超时自检 + 指数退避自动重连。

**自定义配置（V1.0.4 起）**：面板"手势 · 指令映射"列表中，每行右侧开关可单独启用/关闭该手势；
下拉框可把该手势重绑到任意执行指令（允许多个手势绑同一指令；双手缩放为连续会话，指令固定为页面缩放，
只能整体开关）。所有配置即时生效并持久保存，"恢复默认"一键还原。关闭标签页仍额外受
"允许手势关闭标签页"总开关约束（双重保险）。

使用建议：距摄像头 40~70cm，手势保持时手尽量不动；双手缩放保持双手完整入画，
摇完停下即自然结束会话。灵敏度低/中/高三档可调。

## 三、架构（为什么这样拆）

MV3 扩展的 Service Worker 没有 DOM、不能用摄像头，因此：

```
panel/ 侧边栏页面（常驻扩展页，安全上下文）
  ├─ getUserMedia 摄像头 + <video> 预览
  ├─ engine/gesture-engine.js  MediaPipe Hands 推理 + 全部手势状态机
  └─ 动作分发：
       视频播放暂停 / 缩放 ──chrome.tabs.sendMessage──▶ content/controller.js（目标网页内）
       切/关标签页     ──chrome.runtime.sendMessage──▶ background.js（代执行 tabs API）
```

- **侧边栏面板**：唯一能持续持有摄像头 + 全量 chrome API 的常驻界面；带预览画面、
  手部骨架叠加、手势卡片高亮、关闭标签倒计时环、灵敏度设置、动作日志。
- **内容脚本**：只接收指令做两件事 —— 视频播放/暂停（选页面中最大的 video）与 `documentElement.style.zoom` 整页缩放。
- **background**：代执行 `chrome.tabs.remove`；带护栏——扩展自己的页面不允许被手势关闭。

## 四、从原项目移植的核心机制

完整清单见 `docs/原项目实现分析.md`，要点：

- 21 关键点几何比例判定（掌心尺寸归一化 → 对手与摄像头远近不敏感）
- 单手 handedness 锁定，离开 900ms 才允许换手
- 自适应指数平滑（小幅抖动 α=0.22 滤噪，大幅移动 α=0.82 保跟手）
- 静止死区 + 1.7× 唤醒倍率（迟滞，消除悬停时“自己飘”）
- 捏合双阈值迟滞 + 双击时间窗 + 封锁周期
- 横扫的 待命→起笔→总位移定方向→冷却→回手停稳重新待命 状态机
- 30fps 送帧节流、单飞 busy、超时自检、指数退避自动重连、失败降级提示
- generation 计数器防异步竞态

针对“控制浏览器”的改造：

- 比耶触发的是**不可逆动作（关标签页）**：保持时长从 0.42s 提到 1.8s，配倒计时环与 4s 冷却，设置里可关
- 横扫阈值从 0.02 提到 0.10 且限定 3~25 帧内完成，慢速平移绝不误触
- 砍掉“五指全捏合”手势：与“收拢缩小”语义冲突，减少误触面

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 侧边栏里点启动后**没有弹出摄像头授权窗**、日志提示权限被拒绝 | 这是 Chromium 侧边栏的已知限制（没有弹窗挂载位置，直接拒绝）。点面板底部 **「🔑 没弹摄像头授权窗？点这里授权一次」**，会自动以标签页打开授权页并弹出询问；选「允许」后关闭该标签页，侧边栏即可长期使用（授权按扩展 origin 记住）。也可手动在地址栏输入 `chrome-extension://<扩展ID>/panel/panel.html` 打开授权页，ID 见 `edge://extensions/` |
| 面板显示识别异常/自动重连 | 摄像头被其他应用占用；关掉占用程序或点停止→启动 |
| 缩放/视频控制没反应，日志提示不支持 | `edge://`、`chrome://`、WebStore 页面禁止内容脚本注入，属浏览器安全限制；切到普通网页即可 |
| 刚装好扩展后旧标签页无效 | 内容脚本只注入安装后加载的页面，刷新目标网页 |
| 手不动时页面仍缓慢飘 | 降低灵敏度（低档会加宽静止死区） |
| 缩放后个别网站版式错乱 | CSS `zoom` 在 Chromium 为原生整页缩放，极少数页面适配欠佳；双击捏合即可复位 100% |
| 想彻底停用 | `edge://extensions/` 移除，或在面板点停止释放摄像头 |

## 七、隐私

视频帧仅在本机 WASM 中推理；扩展无远程代码、无网络请求、不上传任何图像或手势数据，
所有模型文件随扩展本地分发（CSP 锁定 `script-src 'self'`）。
